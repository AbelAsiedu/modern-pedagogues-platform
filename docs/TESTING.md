# Testing

- `npm run test:unit` - pure logic (money, permissions, tokens, passwords, validation, env, errors, logger redaction). No database.
- `npm run test:integration` - real PostgreSQL, no mocks. Global setup drops and recreates the `public` schema of `TEST_DATABASE_URL` (the database name must end in `_test`) and applies every migration, so each run also proves migrations work from empty. Covers auth flows, sessions, rate limiter atomicity, audit immutability, constraints and seed idempotency.
- Test-only: the harness disables the audit triggers inside a transaction to wipe tables between tests; a test proves they are re-enabled.
- Also covered: site-text saving/permissions/atomicity, the rich-text renderer, tutor applications and review workflow (including a concurrent-decision race and privacy of the public shape), Kaitlyn's guard, provider request/response handling (with a fake `fetch`), answer pipeline, rate limits, knowledge/prompt contents, and admin permissions.
- Not covered yet: automated browser/E2E tests, payment webhooks, file uploads. No test calls a real AI provider.

Latest: 232 tests (unit + integration) pass; lint, typecheck and production build pass. Manual browser runs (Playwright against the production build; scripts are not in the repo, so they are not automated regression tests) covered: sign-in and cookie flags, banners and the slideshow; the site-text editor (edit, reset, `<script>` and `javascript:` links in a policy, audit entries); a full tutor flow (application with rejected contact details, staff review, incomplete-profile approval refused, approval, public page with no private data leaking, filters, hide); and Kaitlyn (widget open/close/Escape/focus, bullets and links rendered, injected `<script>` not executed, blocked and fallback replies, the API refusing missing/foreign Origin and bad content types, admin knowledge reaching the prompt, the kill switch hiding the widget). For the Kaitlyn run the Google API was replaced by a local stand-in loaded into the server, so the real provider has not been called.
