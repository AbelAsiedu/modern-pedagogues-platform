# Testing

- `npm run test:unit` - pure logic (money, permissions, tokens, passwords, validation, env, errors, logger redaction). No database.
- `npm run test:integration` - real PostgreSQL, no mocks. Global setup drops and recreates the `public` schema of `TEST_DATABASE_URL` (the database name must end in `_test`) and applies every migration, so each run also proves migrations work from empty. Covers auth flows, sessions, rate limiter atomicity, audit immutability, constraints and seed idempotency.
- Test-only: the harness disables the audit triggers inside a transaction to wipe tables between tests; a test proves they are re-enabled.
- Also covered: site-text saving/permissions/atomicity, the rich-text renderer, tutor applications and review workflow (including a concurrent-decision race and privacy of the public shape), Kaitlyn's guard, provider request/response handling (with a fake `fetch`), answer pipeline, rate limits, knowledge/prompt contents, and admin permissions.
- Also covered: image processing (formats, resize, EXIF removal, appended scripts, SVG/GIF refused), the media library and its permissions, tutor photo paths, product and price rules, PDF checking, publishing rules, the order and payment-confirmation flow (idempotency, double clicks, concurrent confirmation, who may download), and the Kaitlyn connection test.
- Also covered (stage 5): business-detail validation and token flow, menu/SEO/curricula editing, picture replacement (moves banners and tutor photos, removes the old picture, refuses non-staff), the admin overview limited by role, phone-number handling, and testimonial parsing.
- Also covered (marketplace): PDF inspection (readable, encrypted, scripts, page count), the quality rubric and readiness checklist, creator joining, ownership of listings and covers, price floors and level lists, contact-detail refusal (without rejecting years such as 2019-2023), the submit/review/approve/changes/decline lifecycle, rubric gates, the lost-update and concurrent-reviewer guards, replacing an approved file, hiding/showing, take-down and restore, free downloads and their count, paid files staying locked, the 70/30 split fixed at payment, payout limits (including two at once), and creator suspension.
- Not covered yet: automated browser/E2E tests, calls to the real Paystack (every Paystack test uses a fake), malware scanning. No test calls a real AI provider.
